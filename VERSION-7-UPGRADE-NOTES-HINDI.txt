NEXT LEVEL LEARNING ACADEMY · VERSION 7

इस अपडेट में Admin Panel के अंदर Student Learning Progress Report जोड़ी गई है।

नई सुविधाएँ:
1. सभी Courses के Enrollments की सूची।
2. Course के अनुसार Filter।
3. विद्यार्थी का नाम और उपलब्ध Phone Number।
4. प्रत्येक Course में पूरे किए गए Chapters और कुल Published Chapters।
5. Completion Percentage और औसत Completion Summary।
6. Student Progress CSV Export।
7. Refresh बटन से नवीनतम Progress डेटा।

तकनीकी जानकारी:
- Existing Supabase tables: course_enrollments, profiles, courses, course_chapters, chapter_progress.
- कोई नया SQL या database migration आवश्यक नहीं है।
- Report मौजूदा Admin login और Supabase RLS policies के अंतर्गत काम करती है।
- अधिकतम 500 नवीनतम Enrollments दिखाए जाते हैं।
- जिन Courses में Published Chapters नहीं हैं, उनका progress N/A रहेगा।
- यदि डेटा लोड न हो, तो Admin की संबंधित SELECT/RLS permissions और chapter-progress.sql setup जाँचें।
