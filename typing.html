04 / QUICK GUIDE

Keyboard Setup Guide

Hindi typing शुरू करने से पहले सही input layout चुनें।

EN

English Keyboard

English practice के लिए सामान्य QWERTY keyboard का उपयोग करें। Home row पर fingers रखकर typing करें।

  • Left hand: A S D F
  • Right hand: J K L ;
  • Spacebar के लिए thumb
र

Hindi · Remington Gail

Remington layout चुनकर अपने computer में उसी input method को सक्रिय करें। यह legacy Hindi typing सीखने वालों के लिए उपयोगी है।

  • Windows में Hindi keyboard layout जोड़ें
  • Remington layout select करें
  • Unicode output verify करें
अ

Hindi · InScript

InScript एक standard Hindi keyboard layout है। अपने operating system में Hindi InScript input enable करें।

  • Hindi InScript select करें
  • Keyboard map देखकर अभ्यास करें
  • नियमित छोटे sessions करें

ध्यान दें: Remington Gail और InScript के अक्षर-स्थान अलग होते हैं। इस शुरुआती version में website अभ्यास और परिणाम track करती है; वास्तविक key mapping operating system/input tool संभालता है।
